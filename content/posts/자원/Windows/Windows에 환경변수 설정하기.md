# Windows에 환경변수 설정하기

Windows를 사용하면서 `choco` 혹은 `scoop`등의 패키지 관리자를 통하여 프로그램을 설치하면 Powershell 이나 Wsl에서 해당 프로그램에 cli를 통해 바로 접근이 가능하다.

만약 구글링을 하다가 이미 빌드된 실행파일의 경우에도 환경변수 설정을 통하여 cli를 통해 바로 접근할 수 있도록 설정이 가능하다.

## 실행파일 경로 설정

내가 windows에 빌드된 프로그램들을 설정하는 방법은 사용자 폴더 내부에 `bin` 폴더를 따로 만들고 해당 폴더 안에 실행 프로그램들을 전부 저장하는 것이다.

이렇게 하면 환경변수에 해당 `bin`폴더만 설정해 주고 새로운 프로그램을 받을때마다 `bin`폴더에 넣어주기만 하면 되서 간편하고 어디에 저장했는지 잊어버릴 이유도 사라진다.

```bash
mkdir /users/사용자 이름/bin
```

환경변수는 제어판->고급 시스템 설정 보기->고급(탭)->환경 변수에 들어가서 설정할 수 있다.
