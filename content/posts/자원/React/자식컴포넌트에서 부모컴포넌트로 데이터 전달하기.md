# 자식컴포넌트에서 부모컴포넌트로 데이터 전달하기

두가지 방법이 있다 한가지는 부모가 가지고 있는 상태를 조작할 수 있는 리모콘을 만들어 자식에게 전달하는 방식 다른 하나는 contextAPI 혹은 다른 상태 관리 프로그램을 활용해 데이터를 전달하는 것이다.

## 리모콘을 전달해보자.

리엑트는 기본적으로 `state`와 `props`로 이루어져 있다. `props`는 읽기 전용 이기 때문에 직접 수정은 불가능 하다. 다만 객체를 넘기면 된다. 함수의 경우에도 객체이기 때문에 `props`에 `setState` 혹은 **콜백 함수** 를 자식 컴포넌트로 넘기게 되면 자식 컴포넌트에서 부모에서 선언된 상태를 조작할 수 있게 된다.

```jsx
// 부모 컴포넌트
function ParentComponent() {
  const [parentData, setParentData] = useState("");

  return (
    <div>
      <h2>부모 컴포넌트</h2>
      <p>데이터: {parentData}</p>

      {/* setState 함수 자체를 props로 전달 */}
      <ChildComponent setParentData={setParentData} />
    </div>
  );
}

// 자식 컴포넌트
function ChildComponent({ setParentData }) {
  const [inputValue, setInputValue] = useState("");

  const handleChange = (e) => {
    setInputValue(e.target.value);
  };

  const handleSubmit = () => {
    // 부모로부터 전달받은 setState 함수 직접 호출
    setParentData(inputValue);
  };

  return (
    <div>
      <h3>자식 컴포넌트</h3>
      <input
        type="text"
        value={inputValue}
        onChange={handleChange}
        placeholder="데이터 입력"
      />
      <button onClick={handleSubmit}>부모 상태 업데이트</button>
    </div>
  );
}
```
