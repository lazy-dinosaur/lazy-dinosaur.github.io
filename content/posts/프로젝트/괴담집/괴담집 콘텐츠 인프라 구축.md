# 괴담집 콘텐츠 인프라 구축

Strapi 를 통해 DB 내부의 컨텐츠를 관리하고 n8n을 활용하여 ai를 통한 자동 이야기 생성 및 컨버팅을 진행할 예정이다.

## DB 스키마의 설정

사실 백엔드를 잘 모르기 때문에 기획 파일들을 ai에 넘기고 어떤식으로 저장되어야 하는지 물어봤다.

콜렉션은 `Assets`,`Asset Categories`, `Asset Subcategories`, `Stories` 가 있고 각각의 형태는 다음과 같다.

### Asset Category

음향인지, 배경음인지, 글자효과인지 등 효과에 대한 대분류를 나타내는 역할을 함

- name: 카테고리 이름
- description: 설명
- assets_subcategory: 관계형 데이터
- assets: 관계형 데이터

### Asset Subcategory

대분류 안에 발소리효과인지 심리효과인지 등 세부 분류를 나타내는 역할을 함

- name: subcategory 이름
- description: 설명
- category: 관계형 데이터
- assets: 관계형 데이터

### Asset

n8n에서 불러와 실제로 사용할 효과들의 정보를 prompt 에 집어넣어 RAG를 구현하는 역할을 함

- tag_name: 실제로 사용하게 되는 이름 `WOOD_CREAK` 같은 웹에서 사용될 형태
- display_name: DB에서 쉽게정 확인할 이름
- description: 효과에 대한 설명
- usage_guide: ai가 참고해야 하는 사용 설명서
- keywords: 효과를 찾기 쉽게 하기 위한 검색 키워드(후에 벡터 데이터로 활용할 예정)
- category: 관계형 데이터
- subcategory: 관계형 데이터
- file: mp3,svg 등 실제 미디어 파일
- implementation_type: 효과가 파일만 제생하는것인지 코드와 같이 적용되는것인지 코드로만 구현되는것인지에 대한 분류

### Story

n8n 을 통해 실제로 만들어진 이야기의 데이터를 저장하여 웹앱에서 접근 가능 할 수 있도록 하는 역할

- title: 이야기 제목
- author: 기본값'ai'
- story_summary: 이야기 요약
- tags: 이야기 태그
- converted_json: n8n을 통해 편집된 이야기의 json 파일
- view_count: 시청 수
- original_text: n8n으로 생성된 최초의 이야기

## 1.Strapi 설치하기

[공식문서](https://docs.strapi.io/)

Strapi는 괴담집의 전체적인 콘텐츠를 추가,삭제,편집,수정을 위한 역할을 한다.
가장 큰 역할은 RAG를 위해 새로운 효과의 추가 및 편집이다.

### 1.1 Strapi 프로젝트 생성

```bash
npx create-strapi-app@latest goedamjip-contents-manager
```

### 1.2 필수 패키지 설치

```bash
npm install strapi-provider-upload-supabase
```

## Strapi에 Supabase 프로젝트 설정

[대시보드](https://supabase.com/dashboard)

Supabase와 연결하기 위해서 supabase의 api 키값들이 필요하다.

### 2.1 Supabase 프로젝트 생성

1. Supabase 대시보드에서 'New project'를 클릭하여 새 프로젝트를 생성한다.
2. 프로젝트 이름과 데이터베이스 비밀번호를 입력하고, 리전을 선택한다. 비밀번호는 안전한 곳에 보관(추후 API 연결에 필요).

![supabase 프로젝트 생성](_assets/attachments/괴담집/supabase-create-project.png)

### 2.2 데이터 베이스 연결 정보 확인 및 .env 설정

프로젝트 생성이 완료되면, 상단 헤더의 **connect** 를 클릭하여 나타나는 창의 접속 주소 아래 **View parameters**를 클릭하여 정보를 확한다.

- `Host`
- `Port`
- `User` (`postgres`)
- `Password` (프로젝트 생성 시 입력한 비밀번호)
- `Database name` (`postgres`)

확인한 정보들을 기반으로 `.env`에 설정을 추가한다.

```env
DATABASE_CLIENT=postgres
DATABASE_HOST=db.<your-project-ref>.supabase.co
DATABASE_PORT=<your-database-port>
DATABASE_NAME=postgres
DATABASE_USERNAME=postgres
DATABASE_PASSWORD=<your-database-password>

```

### 2.3 Storage Bucket 생성 및 Strapi 설정

Supabase DB 와 연결을 통해 기본적인 데이터를 저장할 순 있지만 Bucket을 사용 해야 실제 mp3과 같은 파일 들을 저장하기 위해서는 bucket storage의 생성과 설정이 필요하다.

1. 왼쪽 메뉴에서 **Storage**로 이동하여 'New bucket'을 클릭한다.
2. Bucket 이름을 입력합니다 (예: `strapi-uploads`). **Public bucket**으로 설정한다.

![supabase api key](_assets/attachments/괴담집/supabase-api키.png)

### 2.4 API 키 확인

왼쪽 메뉴에서 **Settings > API**로 이동하여 다음 정보를 확인한다.

- `Project API URL`
- `Project API keys`의 `anon` `public` 키

왼쪽 메뉴에서 **Settings > Data API**로 이동하여 다음 정보를 확인한다.

- `Project API URL`

### 2.5 Strapi에 모듈 추가 및 .env 설정

앞서 확인한 정보들을 프로젝트 에서 사용하기 위해 `.env`파일에 적절한 키값으로 추가한다.

```env
SUPABASE_URL=<your-dataApi-url>
SUPABASE_ANON_KEY=<your-anon-apiKey>
SUPABASE_BUCKET=<your-bucket-name>
```

프로젝트 폴더 안에 `plugins.ts`에 설치한 `strapi-provider-upload-supabase`를 추가하고 설정을 입력한다.

- 경로: `config/plugins.ts`

```typescript
module.exports = {
  provider: "supabase",
  providerOptions: {
    apiUrl: process.env.SUPABASE_API_URL,
    apiKey: process.env.SUPABASE_API_KEY,
    bucket: process.env.SUPABASE_BUCKET,
    directory: process.env.SUPABASE_DIRECTORY,
    options: {},
  },
};
```

## 설치한 Strapi 사용하기

### 3.1 Collectoin의 설정

[[#db-스키마의-설정]]에서 계획한 대로 Strapi의 콜렉션을 설정해야 한다.

- 먼저 `npm run dev`를 통해 개발 서버를 실행한다.(개발 서버를 실행해야 DB의 스키마 변경이 가능)
  ![strapi 콜렉션 추가](_assets/attachments/괴담집-strapi-new-collection.png)

- 프로젝트에서 사용될 DB는 초안 작성 개념이 없기 때문에 `advanced settings`에서 Draft & publish 기능을 꺼준다.

- 이후 계획한 스키마 대로 차근차근 필드를 추가해 주면 된다.
  ![strapi 필드값 추가](_assets/attachments/괴담집/strapi-field-adding.png)

### 3.2 Media Library

효과음으로 사용할 음향 효과와 화면 효과로 사용할 이미지 파일들을 저장하기 위해서 [[#23-storage-bucket-생성-및-strapi-설정]]을 하였다.

이 실제 파일들은 Strapi 왼쪽 메뉴에 Media Library 탭을 통해 Bucket에 업로드 하여 관리할 수 있다.

![strapi-media-library](_assets/attachments/괴담집/strapi-media-library.png)

해당 탭 내에서 폴더구조를 만들어 파일들을 정리하여 보관할 수 있다. 또한 Collection에서 file 필드를 추가하여 추가된 파일을 찾아 연결시킬 수 있다.
